# SSI Portal — Group 5 Capstone Project
**Student & Alumni Connect**  
Conestoga College | 2026  

---

## About
A full-stack web platform connecting Conestoga College Students and Alumni in one unified digital space.

---

## Tech Stack
| Layer       | Technology                                |
|-------------|-------------------------------------------|
| Frontend    | React.js, React Router, Context API        |
| Backend     | ASP.NET Core (.NET 6), REST API            |
| Database    | MongoDB Atlas                              |
| Real-time   | SignalR WebSockets                         |
| Auth        | JWT Bearer Tokens, BCrypt                  |
| Scraping    | HtmlAgilityPack                            |
| Microservice| ASP.NET Core Event Service                 |

---

## Prerequisites
- Node.js 18+
- .NET 6 SDK
- MongoDB Atlas account
